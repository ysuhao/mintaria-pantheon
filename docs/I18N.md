# 界面三语

界面支持英文、韩文、中文，右上角切换。切换由 `EditorBase` 提供，设置对全系列生效，插件不用自己放按钮。

## 写法

```cpp
EditorBase (p, { "JANUS", { "Gate", "게이트", "门限" }, "I" })
Dial dial (p.apvts, "threshold", { "Threshold", "스레숄드", "阈值" }, true);
Meter meter (p.inputMeter, { "Input", "입력", "输入" });
Segmented mode (p.apvts, "mode", { { "Fast", "빠름", "快" }, { "Slow", "느림", "慢" } });

// 自绘文字和 getLookaheadText() 在绘制时取当前语言：
g.drawText (mint::ui::tr ({ "Off", "끔", "关闭" }), area, juce::Justification::centred);
```

- 字体用 `mint::ui::bodyFont()`，它按语言选字体。不要写死字体名。
- `tr()` 只在绘制或 `languageChanged()` 里调用，不要在构造时取值后存成 `juce::String`。
- `juce::Label`、`TextButton` 这类自己存文字的控件，覆盖 `EditorBase::languageChanged()` 重设文字。
- 只用于界面。**参数名、参数 ID、选项名不改**，它们是宿主自动化和测试脚本的依赖，改了会破坏用户工程。`Segmented` 的显示文字用 `labels` 给。
- 数值和单位（dB、ms、Hz、kHz）不翻译。
